⚠️ Render पर links हमेशा के लिए रखने के लिए

  1. Render Dashboard → तुम्हारी service → Disks → Add Disk
  2. Mount path: /var/data
  3. Environment → AAPKA_DATA=/var/data
  4. Save + Redeploy एक बार

बिना Persistent Disk के free Render redeploy पर files मिट जाती हैं — ये Render की limitation है, tool की नहीं। Disk लगाने के बाद links permanent रहेंगे।
