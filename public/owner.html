Create a Separate Link Pair for Each Company

  1. Enter the company name below and select Create.
  2. Two links will be generated:
    • Tool link — For your company team. Keep this link private.
    • Customer link — Add this link to your app’s Help button.
  3. Share the Tool Link only with your authorized team.
  4. Create a new pair for every company. Each company’s data stays separate.

Customer Link: add it to your app’s Help button. Tool Link: keep it private for your team. Each company has its own separate workspace. For persistent data on Render, configure a disk and set AAPKA_DATA=/var/data.

The Tool Includes 6 Dashboards

  1. Overview — Today’s cases and automation summary
  2. Employee / Agent — Inbox, replies, and suggested actions
  3. CEO / ROI — Hours saved, cases, and cost overview
  4. Integrations — Salesforce / Zendesk / Payment integrations (the company enters its own API keys)
  5. History & Audit — That company’s refunds and orders (other companies’ data is hidden)
  6. Customer portal — Opens through the separate Customer Link

Refund and CRM integrations will go live after the company enters its own API keys in Integrations and selects Test Connection. Without API keys, demo mode is used.
